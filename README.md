# 크레이지 아케이드 (Crazy Arcade)

추억의 **크레이지 아케이드**를 HTML5 Canvas로 재현한 웹 게임입니다.
외부 라이브러리·이미지·사운드 파일 없이 **`index.html` 단일 파일**로 동작하며,
모든 캐릭터와 타일, 아이템은 Canvas 도형으로 직접 그렸고 효과음은 Web Audio API로 합성합니다.

![타이틀](screenshots/title.png)

## 플레이 방법

`index.html` 을 브라우저로 열기만 하면 됩니다. 설치나 빌드 과정이 없습니다.

```bash
git clone https://github.com/nsj9164/crazyarcade.git
cd crazyarcade
start index.html      # macOS: open index.html
```

## 조작

| 키 | 동작 |
|---|---|
| `방향키` / `WASD` | 이동 |
| `SPACE` | 물풍선 설치 |
| `ENTER` | 확인 / 다음 |
| `P` | 일시정지 |
| `M` | 음소거 |
| `ESC` | 뒤로 / 타이틀 |

물방울에 갇히면 **방향키를 연타**해서 탈출하세요. 5초 안에 못 나오면 목숨이 하나 줄어듭니다.

## 게임 규칙

- 물풍선은 설치 후 **3초 뒤 십자 모양**으로 터집니다.
- 물줄기에 닿은 **다른 물풍선도 연쇄 폭발**합니다.
- 상자를 부수면 **34% 확률로 아이템**이 나옵니다.
- 물에 맞으면 물방울에 갇히고, 5초 안에 탈출하지 못하면 사망합니다.
- 스테이지의 **적을 모두 물리치면 클리어**. 남은 시간은 보너스 점수가 됩니다.
- 강화한 능력치는 다음 스테이지로 이어집니다. (사망 시 일부 감소)

## 아이템

| 아이템 | 효과 |
|---|---|
| 물풍선 | 동시에 놓을 수 있는 물풍선 +1 |
| 물줄기 | 폭발 길이 +1 |
| 롤러 | 이동 속도 +1 |
| 바늘 | 갇히는 즉시 자동 탈출 (1회 소모) |
| 하트 | 목숨 +1 |

## 적 AI

단순한 랜덤 이동이 아니라, 매 프레임 다음을 계산합니다.

- **위험 지역 예측** — 설치된 모든 물풍선의 폭발 반경을 미리 계산해 위험 타일 집합을 만듭니다.
- **회피** — 위험 지역에 있으면 BFS로 가장 가까운 안전 타일을 찾아 도망갑니다.
- **추격** — 안전할 때는 플레이어를 쫓고, 멀면 가까운 상자를 부수러 갑니다.
- **자폭 방지** — 물풍선을 놓기 전에 *놓았다고 가정한* 위험 지도를 다시 계산해, **탈출로가 있을 때만** 설치합니다.
- **협동** — 물방울에 갇힌 동료를 발견하면 다가가 터뜨려 구해줍니다.

## 기술 노트

- 순수 JavaScript + Canvas 2D, 의존성 0개, 빌드 도구 없음
- 정적 배경(바닥·벽)은 스테이지 시작 시 오프스크린 캔버스에 한 번만 렌더링
- 픽셀 단위 이동 + 모서리 자동 보정(corner nudging)으로 부드러운 조작감
- 효과음은 파일 없이 Web Audio 오실레이터로 실시간 합성
- 맵은 매번 랜덤 생성되며, 스폰 주변은 항상 비워두고 **모든 타일이 도달 가능**하도록 보장

## 검증

- 헤드리스 환경에서 실제 게임 루프를 **11,454 프레임** 구동 — 7개 씬 전부 통과, 런타임 에러 0건
- 맵 생성 **480회**(8스테이지 × 60회) 검사 — 전부 완전 연결, 막힌 스폰 0건
